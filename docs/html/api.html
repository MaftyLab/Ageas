API Reference

This section provides detailed API documentation for the modules, classes, and functions in the Ageas package.

Core Objects

ageas.Hangar(config_folder)

Collection of candidate Unit models and configs.

ageas.Deck(squad[, n_dataloader_workers, ...])

Sortie deck that trains, evaluates, and explains a squad of units.

ageas.Unit(tail, unit_type, config[, ...])

Single classifier model bundled with its configuration and runtime state.

Operations

ageas.n_kfold_selection(hangar[, ...])

N-iteration k-fold selection of top-performing models.

ageas.n_iter_boost_selection(hangar[, ...])

N-iteration boost selection driven by per-class explanation scores.

ageas.n_iter_extraction(hangar[, ...])

N-iteration extraction of top regulatory factors per class.

Feature-Routed Pipeline (v2)

The label-free workflow (see Feature-routed pipeline (Ageas v2)) and the objects it returns.

ageas.run_pipeline(terminal_dataset, ...[, ...])

Run Ageas v2 on one dataset.

ageas.PipelineResult(deck, profile, panel, ...)

Everything one pipeline run produced.

ageas.moe_selection(hangar[, query_dataset, ...])

Route every unit to its key features and integrate the ones that help each other.

ageas.MoE_Deck(experts, weights, oof, features)

Integrated experts of an Ageas v2 run.

Data Profile and Panel Design (v2)

ageas.profile_dataset(terminal_x, ...[, ...])

Label-free profile of one dataset.

ageas.design_panel(profile[, use_rules])

The units a dataset's profile calls for.

ageas.extend_panel(panel, losses)

Units one step past the edge of a range where validation prefers that edge.

ageas.write_panel(panel, folder)

Write panel as an Ageas config folder; returns its path.

ageas.UnitSpec(name, type, config, ...)

One generated unit of the panel.

ageas.check_strategy(panel, oof_probs, labels)

Whether validation bears out what each panel rule expected.

Validation, Routing and Integration (v2)

ageas.shift_weights(terminal_x, query_x[, ...])

Weight of every terminal cell for shift-aware validation.

ageas.explain_unit(model, unit_type, dataset)

Per-class, class-contrastive attribution of one trained unit.

ageas.key_features(attribution, mass[, floor])

Features a unit relies on at one pruning level.

ageas.search_ladder(levels, full_score, ...)

Pruning level of a unit, searched down the ladder.

ageas.no_harm_selection(oof_probs, labels[, ...])

Weights of the units that improve the ensemble's OOF log-loss.

ageas.competent_units(oof_probs, labels[, ...])

Units whose out-of-fold balanced accuracy is within tolerance of the best unit's.

ageas.select_committee(query_probs, ranked)

The committee drawn from ranked units, judged on their query probabilities.

ageas.vote(member_probs[, rule, groups, mixture])

Equal-weight soft vote of the members' class probabilities.

Graph Stage (v2)

ageas.graph_stage(vote, features, labels, ...)

Fuse the walk into the vote when the data allows it; otherwise pass the vote through.

ageas.graph_fate(features, labels[, kind, ...])

Absorption probabilities of every cell over the diffusion-space neighbour graph.

ageas.fuse(vote, walk[, weight])

Two-class probabilities from the vote and the walk.
