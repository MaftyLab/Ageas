ageas.design_panel

ageas.design_panel(profile: dict, use_rules: bool = True) → list

The units a dataset’s profile calls for.

Parameters:

  • profile – Output of profile_dataset().

  • use_rules – If False, no rule shapes the panel (middle regularisation and capacity, L2 penalties, one naive-Bayes smoothing): the fixed panel of the R2.4 ablation. Data-type checks (naive Bayes for non-negative input, the SVC size limit) and the networks’ schedule by cell count still apply.

Returns:

UnitSpec list, one per unit.
