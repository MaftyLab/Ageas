ageas.UnitSpec

class ageas.UnitSpec(name: str, type: str, config: dict, shaped_by: list = <factory>, favoured_by: list = <factory>, disfavoured_by: list = <factory>, axis: str = None, position: float = None)

Bases: object

One generated unit of the panel.

Variables:

  • name – Unit name within its type (the config file’s stem).

  • type – Ageas model type ('logreg', 'xgb', …).

  • config – The Ageas unit configuration.

  • shaped_by – Rules that set this unit’s settings.

  • favoured_by – Rules that expect this unit to validate well.

  • disfavoured_by – Rules that expect this unit to validate poorly.

  • axis – The ordered setting this unit varies with others of its family ('logreg': C; 'mnb': smoothing; 'xgb': depth and rounds; 'mlp', 'resnet': size), or None.

  • position – The unit’s place on its axis (log10 C, log10 alpha, boosting step or network size).
