ageas.vote

ageas.vote(member_probs: dict, rule: str = 'mean', groups: dict = None, mixture: numpy.ndarray = None) → dict

Equal-weight soft vote of the members’ class probabilities.

Parameters:

  • member_probs – unit_id -> (n_cells, n_classes) probabilities.

  • rule – 'mean' averages the probabilities; 'logit' averages their logarithms and renormalises (the normalised geometric mean; with two classes, the average log-odds), so a surer member counts for more.

  • groups – Optional unit_id -> group (e.g. the model type). The members of each group vote among themselves first, then every group has one voice, so a type with many variants does not outvote the rest.

  • mixture – Optional (n_cells, n_classes) probabilities of the no-harm mixture. The committee’s average and the mixture are then averaged by rule with equal weight, so the mixture counts as much as the whole committee.

Returns:

probs (the committee’s average, with the mixture when one is given), agreement (share of members whose own call is that call) and disagreement (entropy of the members’ plain average minus their average entropy, in bits: 0 when every member gives the same distribution).
