ageas.key_features

ageas.key_features(attribution: pandas.DataFrame, mass: float, floor: int = 0) → list

Features a unit relies on at one pruning level.

For each Class_{i}_Scores column the features are ranked by score, and the smallest top-ranked prefix whose positive scores add up to mass of the column’s positive total is kept, topped up to floor features. Only positively scored features count: a feature that does not push towards a class is never kept on that class’s behalf.

Parameters:

  • attribution – Per-feature, per-class score table; _Std columns are ignored.

  • mass – Fraction of each class’s positive attribution to keep, in (0, 1].

  • floor – Minimum number of positively scored features per class.

Returns:

The union over classes, in the table’s feature order.
