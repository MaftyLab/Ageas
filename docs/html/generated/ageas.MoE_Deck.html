ageas.MoE_Deck

class ageas.MoE_Deck(experts: dict, weights: dict, oof: dict, features: list, provenance: dict = None, competent: list = None)

Bases: object

Integrated experts of an Ageas v2 run.

Variables:

  • experts – Mapping unit_id -> Expert for every integrated or competent unit.

  • weights – Mapping unit_id -> weight from the no-harm selection; the weights sum to one.

  • competent – Units whose out-of-fold balanced accuracy is close to the best, ranked by out-of-fold loss: the committee’s candidates.

  • oof – Out-of-fold record of the run: per-unit probabilities on every terminal cell ('probs'), the labels, the fold indices, and each unit’s per-fold level, features and validation losses.

  • features – Feature names of the terminal corpus.

  • provenance – Which ageas the run imported (ageas_path) and the git state of that checkout (ageas_commit, ageas_dirty).

__init__(experts: dict, weights: dict, oof: dict, features: list, provenance: dict = None, competent: list = None) → None
debrief(exp_dataset=None, exp_sample_limit: int = None, device: str = None, **kwargs) → pandas.DataFrame

Integrated per-class attribution over all features.

Each expert explains exp_dataset on its own features, so the features it does not use score zero for it. The experts’ tables are combined as A_c = sum_e w_e d_{e,c} with the no-harm weights.

Parameters:

  • exp_dataset – Labelled dataset to explain.

  • exp_sample_limit – Cells per class explained by Integrated Gradients for neural-network experts.

  • device – Device for Integrated Gradients. None uses each expert’s own accelerator.

  • kwargs – Forwarded to explain_unit().

Returns:

Table indexed by features with one Class_{i}_Scores column per class.

predict(query_dataset=None, batch_size: int = 10, num_workers: int = 1, return_members: bool = False) → tuple

Ensemble-predict with the no-harm weights.

Each expert sees only its own features, looked up by name in query_dataset.features, and the experts’ probabilities are averaged with weights.

Parameters:

  • query_dataset – Dataset to score.

  • batch_size – Batch size for the prediction dataloader.

  • num_workers – Number of dataloader workers.

  • return_members – If True, also return the probabilities of every expert, weighted or not.

Returns:

(probs, labels), or (probs, labels, member_probs) with return_members=True. labels is None for an unlabelled dataset.
