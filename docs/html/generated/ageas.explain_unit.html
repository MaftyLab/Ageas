ageas.explain_unit

ageas.explain_unit(model, unit_type: str, dataset, exp_sample_limit: int = None, device: str = 'cpu', **kwargs) → pandas.DataFrame

Per-class, class-contrastive attribution of one trained unit.

Parameters:

  • model – Trained classifier of the unit.

  • unit_type – The unit’s model type key (e.g. 'mlp', 'logreg').

  • dataset – Labelled corpus exposing features and label_dict.

  • exp_sample_limit – For neural networks, the largest number of correctly predicted cells explained per class, spread evenly over their loss order. None explains all of them.

  • device – Device for Integrated Gradients.

  • kwargs – Forwarded to ageas.tool.Basic_Clf_Explainer for neural networks (e.g. exp_step), otherwise to the model’s explain.

Returns:

Table indexed by feature with one Class_{i}_Scores column per class.
