ageas.search_ladder

ageas.search_ladder(levels: list, full_score: float, score_at, relative_delta: float, choice: str = 'sparsest')

Pruning level of a unit, searched down the ladder.

Levels are tried from weakest to strongest, and the search stops at the first level whose score exceeds full_score * (1 + relative_delta). The tolerance is relative because terminal cells are often nearly separable: with an all-feature loss of 0.005, any absolute margin worth having elsewhere lets through versions several times worse. Scores are losses (lower is better), so a pruned version that beats the all-feature one always passes.

Parameters:

  • levels – Mass levels ordered from weakest to strongest pruning, e.g. [0.95, 0.8, 0.6, 0.4].

  • full_score – Validation loss of the all-feature version.

  • score_at – Callable mapping a level to the validation loss of the version pruned to that level.

  • relative_delta – Largest loss increase accepted for a narrower expert, as a fraction of full_score.

  • choice – 'sparsest' keeps the strongest passing level, trading up to relative_delta of loss for fewer features. 'best' keeps the version with the lowest loss among those tried, the all-feature one included (ties go to the weaker pruning): the unit works on the features it works best on, and the tolerance only bounds the search.

Returns:

The chosen level, or None when the unit keeps all features.
